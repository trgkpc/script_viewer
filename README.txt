発表原稿ビューア
================

Python 3.10 以上 + tkinter で動く、デスクトップ用の原稿表示アプリです。
キーボード監視には pynput を使用します。初回のみ追加インストールが必要です。
インストール後のアプリ動作にはネットワーク接続や外部サービスを使用しません。

使い方
------
1. ZIP を展開します。
2. script_viewer.py と同じフォルダ直下に、UTF-8 の発表原稿 .md を置きます。
3. ターミナルでこのフォルダに移動し、初回の準備と起動を行います。

   Windows:
     py -m pip install -r requirements.txt
     py script_viewer.py

   macOS / Linux:
     python3 -m pip install -r requirements.txt
     python3 script_viewer.py

4. 「キーボード監視」がオンになっていることを確認します。
5. 原稿とプレゼンアプリの開始ページを合わせ、「スタート」を押します。
6. プレゼンアプリを選択して発表します。右矢印でプレゼンを進めると原稿も進みます。

原稿アプリは起動したままにしてください。前面にする必要はありません。
別モニターに原稿を置いたり、プレゼン画面と並べて表示したりできます。
インストール済みの環境では、次回から起動コマンドだけで使えます。
監視が使えない場合は画面上に表示され、「監視の設定」で対処方法を確認できます。
その場合も、原稿アプリにフォーカスを当てた従来の操作は使えます。

実際の原稿 .md が1つなら自動で開きます。複数なら選択画面が出ます。
実際の原稿がなければ、同梱の sample.md（操作確認用3ページ）を開きます。
README.md と AGENTS.md は自動読込の対象から外します。
「原稿を開く」ボタン、またはファイル名指定でも読み込めます。

  python3 script_viewer.py "発表原稿.md"

原稿の形式
----------
既存の原稿の形式を、そのまま使えます。

  ## Chapter 3：学習・評価ループによるコーパス構築（p13–32）

  **章の時間：17分30秒／章終了時の累計：28分30秒**

  ### p13. 5秒／11分05秒

  続いて、TTSOpsについて説明します。

  ### p14. 1分05秒／12分10秒

  まず、一つ目の課題である、学習データの品質について説明します。

見出しの左の時間 = このページに使える時間
見出しの右の時間 = このページ終了時点の累計目安

・「／」「/」のどちらでも使えます。
・「1分15秒」「75秒」「01:15」「0:01:15」に対応しています。
・累計を省略すると、各ページの持ち時間から計算します。
・時間のない「### p1.」も表示できますが、時間の目安は未設定になります。
・ページ番号は昇順で、重複しないようにしてください。
・# / ## の章見出しと章の時間は、読み上げ本文に含めません。
・本文はプレーンテキスト表示です。Markdown の装飾記号はそのまま表示します。
・原稿は開いた時点で読み込みます。編集後は「原稿を開く」で再読込してください。

表示と計測
----------
「このページ」: 現在のページの経過時間・目安・残り時間。
「ここまで」: スタート以降の総経過時間・現在のページ終了時点の累計目安。
時間は 分:秒 と秒数で表示します。超過時には赤くなります。
「経過」と「目安」は同じ大きさ（29ポイント）で表示します。
持ち時間を超えても、自動でページは進みません。

一時停止している間の時間は含めません。
前のページに戻ると、そのページで既に使った時間を引き継ぎます。
最後のページで右矢印または「終了」を押すと計測を止めます。
終了後もページを見返せます。再計測するときは「リセット」を押してください。

途中のページから開始した場合:
総経過時間は 00:00 からです。「ここまで」の目安は開始ページ分から計算します。
原稿に書かれた元の累計時間も、カード下に併記します。
開始ページより前に戻り、累計目安が負になるときは「未設定」と表示します。

操作
----
右矢印 / PageDown   次のページ（最後では終了）
左矢印 / PageUp     前のページ
Space              開始 / 一時停止 / 再開（原稿アプリを選択しているとき）
上下矢印           原稿をスクロール
A＋ / A−           文字サイズを変更
F11                全画面に切り替え
Esc                全画面を解除
右上のページ選択   指定ページに移動

キーボード監視
--------------
起動時はオンです。画面上のチェックボックスで切り替えられます。
オンの場合、左右キー・PageUp・PageDown を他アプリの操作中にも受け取り、
原稿のページを切り替えます。プレゼンアプリへのキー入力は妨げません。
原稿アプリが前面の場合も、一度のキー入力で二重にページが進むことはありません。
ファイル選択や確認ダイアログの操作中は、原稿のページ移動を停止します。
アプリを終了すると監視も終了します。

監視対象の4つのナビゲーションキーだけをページ移動の指示に変換します。
文字入力の保存や外部への送信は行いません。
Space は他アプリ操作中にはタイマーを止めません。
原稿とプレゼンを合わせるときは、左右キー・PageUp・PageDown を使ってください。

これはキー入力に合わせて原稿を1ページずつ移動する方式です。
プレゼンアプリの実際のスライド番号は取得しません。
クリック・Space・番号ジャンプ・スライド内アニメーションでは原稿とずれる場合があります。
ずれた場合は、原稿アプリ右上のページ選択で合わせ直してください。
発表以外のアプリを操作するときは、必要に応じてキーボード監視をオフにしてください。

OS ごとの準備
-------------
macOS:
  システム設定 → プライバシーとセキュリティで、起動に使う Terminal / Python の
  「入力監視」「アクセシビリティ」を確認してください。権限を変更したら、
  起動元のアプリと原稿アプリを再起動します。端末や IDE によって許可対象が異なります。

Windows:
  pynput のインストール後に起動してください。

Linux:
  X11 セッションで使用してください。Wayland では Xwayland 上で動くアプリからの
  キー入力のみ受け取れる場合があり、デスクトップ全体の監視には対応しません。

参考（pynput 公式ドキュメント）:
  https://pynput.readthedocs.io/en/latest/keyboard.html
  https://pynput.readthedocs.io/en/latest/limitations.html

tkinter がない場合
-----------------
tkinter を含む Python 環境が必要です。まず下記で確認できます。
  python3 -m tkinter
Windows の Python インストーラーでは Tcl/Tk を含めてインストールしてください。
Linux では OS の python3-tk パッケージ等が必要な場合があります。
GUI のないサーバーや SSH 環境では、通常はウィンドウを開けません。

原稿の形式だけ確認するには:
  python3 script_viewer.py "発表原稿.md" --check

同梱の sample.md は使い方を示すためのサンプルです。
発表の全59ページの原稿は含まれていません。
